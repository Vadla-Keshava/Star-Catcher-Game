# ✦ Star Catcher Game

A small browser arcade game built with **HTML5, CSS3 and Vanilla JavaScript**.

## 🎮 How to play
- Press **← / →** arrow keys (or **A / D**) to move the rocket.
- Catch ⭐ stars to earn 10 points.
- Avoid 💣 bombs. You have 3 lives.
- Try to beat your best score!

On mobile, use the on-screen arrow buttons.

## ✨ Features
- Responsive layout for desktop and mobile
- Keyboard and touch-friendly controls
- Random falling stars and bombs
- Score, lives and saved high score (`localStorage`)
- Start, restart and game-over states

## 🚀 Run locally
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No frameworks, packages, or build tools required.

## 🧰 Tech stack
- HTML5
- CSS3
- JavaScript (DOM, events, animation frame, localStorage)
